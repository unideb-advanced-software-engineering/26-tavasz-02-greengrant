## About GreenGrant

GreenGrant is a government grant management platform developed as part of Zamunda's Digital Renaissance (ZDR) program. It enables citizens and businesses to apply for green investment subsidies, and allows government administrators to create grants, review applications, and make funding decisions.

This documentation site contains:

- **Specifications** – Software Requirements Specification (SRS), Architectural Characteristics, and Architecturally Significant Requirements
- **Architecture** – Architecture styles, design decisions (ADRs), and C4 system diagrams
- **Decisions** – Detailed Architectural Decision Records covering key design choices

### Key Features

- ✅ Scalable architecture supporting millions of users and grant application bursts
- ✅ Secure design with strong audit trails and compliance requirements
- ✅ Event-driven microservices for resilience and extensibility
- ✅ AI-assisted application review to reduce manual effort
- ✅ Multi-role access (Applicants, Administrators, System Admins)
- ✅ Data residency within Zamunda's territory
